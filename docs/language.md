# pymoji 1.0 语言使用说明

## 源码与排版

- UTF-8 编码，扩展名 `.pymoji`，允许文件头 BOM。
- **所有物理空白在词法分析前删除**，包括名字、数字、文字和注释内部。因此 `数 字` 等同于 `数字`，`1 2` 等同于 `12`；空格不能分隔名字。
- `🔚` 分隔语句，`👉`、`👈` 包围代码块。实际换行和缩进没有语法意义。
- 两条简单语句之间必须有 `🔚`；在 `👈` 或文件结尾前可省略。复合语句的 `👈` 后可直接接下一句。允许连续 `🔚`，括号和列表内部忽略 `🔚`。
- `🤜🤛` 用于表达式分组、函数定义和调用；`🔤🔡` 包围文字。
- 源码任何位置均禁止 ASCII `(`、`)`、`"`、`'`，包括注释和文字。全角圆括号和中文引号也不能作为语法分隔符。
- `💭` 注释到下一个 `🔚` 或文件结束；**实际换行不结束注释**。
- 规范代码按相同列宽排成矩形，使用普通空格补齐行尾。运行时接受自由排版；`--format --width 48` 生成矩形，`--check-rectangle` 检查。列宽由 `pymoji.cell_width` 定义，组合 emoji 不拆开。

## 名字与值

名字支持汉字、Unicode 字母、假名、下划线、非保留 emoji 和非 ASCII 符号；后续可接十进制数字，不能以数字开头。变量、函数、参数和循环变量使用相同规则。关键字字形不能嵌入名字。`高度🍎2` 是一个名字，`高度📍0` 是三个记号。

名字区分大小写，采用 NFC 归一化。emoji 的变体选择符和肤色忽略，名字中的性别保留；关键字另忽略性别后缀。名字中的全角、键帽和其他十进制数字统一为 ASCII 数字：`📦2`、`📦２`、`📦2️⃣` 同名。

值有数字、文字、列表、真假、空值、函数六类。变量不声明类型；普通赋值不复制列表。

| 值 | 写法 |
| --- | --- |
| 整数、小数 | `42`、`2.5`、`➖3`；负号为运算符，无一元正号 |
| 数字简写 | `🔟` 为 10，`💯` 为 100；支持全角、键帽及 Unicode 十进制数字，点可为 `.` 或 `．` |
| 文字 | `🔤内容🔡`；空文字为 `🔤🔡` |
| 列表 | `🎁1,2,🔤甲🔡🎀`；空列表为 `🎁🎀`，允许嵌套 |
| 真假、空值 | `✅`、`❌`、`🕳️` |

小数点前后均需数字，不支持 `.5`、`1.` 或科学计数法字面量。`❌`、`🕳️`、0、空文字、空列表为假，其余为真。

## 文字转义

文字内的物理空白也被删除。需要保留的数据空白使用转义：

| 写法 | 数据 |
| --- | --- |
| `🛡️⬜` | 普通空格 |
| `🛡️🔚` | LF 换行 |
| `🛡️↔️` | TAB |
| `🛡️🔤`、`🛡️🔡`、`🛡️🛡️` | 对应标记本身 |

文字内其他关键字直接作为数据；`💭` 不启动注释，未转义的 `🔚` 是 emoji 本身。未转义的 `🔤` 和未知转义报错。

```pymoji
📢🔤你好🛡️⬜世界🛡️🔚第二行🔡                    
```

输出第一行 `你好 世界`，第二行 `第二行`。

## 语句

下表为语法模板，`值`、`条件`、`主体` 等表示待替换的表达式或语句。

| 写法 | 含义 |
| --- | --- |
| `名字⬅️值` | 赋值；`=` 是比较，不能赋值 |
| `目标⬆️值`、`目标⬇️值` | 加到、减去已有值 |
| `列表📍位置⬅️值` | 修改元素；也支持 `⬆️`、`⬇️` |
| `列表📥值` | 向末尾追加 |
| `📢值1,值2`、`💬值1,值2` | 空格分隔输出；前者结尾换行，后者不换行；允许零项 |
| `🤔条件👉主体👈🤷👉主体👈` | 条件分支；否则可省略，`🤷🤔` 表示否则如果 |
| `🔁条件👉主体👈` | 条件为真时重复 |
| `🔂变量🛫起点🛬终点👣步长👉主体👈` | 范围循环，包含终点；步长默认 1，不能为 0 |
| `🔂变量∈序列👉主体👈` | 遍历列表或文字 |
| `🛑`、`⏭️` | 跳出最内层循环、开始下一轮 |
| `🏭名字🤜参数1,参数2🤛👉主体👈` | 定义函数 |
| `↩️值` | 从函数返回；省略值或自然结束返回 `🕳️` |

赋值和增减的目标必须为名字或下标表达式；`📥` 也受此语法约束。只有函数调用、`👂`、`📤列表` 可以独立成表达式语句，结果丢弃。

范围起点、终点和步长仅在进入时求值一次。列表遍历使用进入时的浅快照；文字按字形遍历。`🛑`、`⏭️` 不能越过函数调用作用于外层循环。`↩️` 只能用于函数。

## 表达式

优先级从高到低；除乘方外，同级从左到右：

| 优先级 | 运算 |
| --- | --- |
| 1 | 调用 `函数🤜参数🤛`、下标 `序列📍位置` |
| 2 | 乘方 `🚀`，右结合 |
| 3 | 前缀负号 `➖`、长度 `📏`、弹出末项 `📤`、查看末项 `👀` |
| 4 | `✖️`、`➗`、向下整除 `✂️`、取余 `🥡` |
| 5 | `➕`、`➖` |
| 6 | `=`、`≠`、`<`、`>`、`≤`、`≥`，支持连续比较 |
| 7 | 非 `🚫` |
| 8 | 并且 `🤝` |
| 9 | 或者 `🔀` |

- `➖2🚀2` 得 -4；`2🚀3🚀2` 得 512。`🚫数=1` 表示数不等于 1。逻辑运算返回真假值，执行短路求值；连续比较的中间表达式只求值一次。
- `📍` 后只接一个小单元及其函数调用：`数组📍位置➕1` 是取出后加 1；`数组📍🤜位置➕1🤛` 才是取下一格。支持链式下标。下标从 0 开始，必须在范围内；整数值小数可用，不支持负下标。
- `📏文字`、文字下标与遍历按字形计数，组合 emoji 视为一个字形。文字单个位置不能赋值。`📤`、`👀` 只接受非空列表。
- 两个整数用 `➗` 恰好整除时得整数，否则得小数。`✂️` 向负无穷取整；余数符号跟除数一致。除以 0、0 的负次幂和负数的非整数次幂报错。
- `➕` 一侧为文字时将另一侧按显示规则转为文字后拼接。文字乘整数表示重复，负次数按 0 处理。
- 列表加列表生成新外层列表，内部引用保留；列表乘整数递归复制子列表，各行独立。
- 相等可比较任意值：数字按数值比较，其他不同类型不等，列表逐元素比较，函数按对象身份比较；`✅≠1`。大小比较仅支持数字对数字、文字对文字、列表对列表；文字按 Unicode 编码，列表按字典序。
- 调用参数和列表项目允许尾逗号；函数定义参数不允许。

## 函数与作用域

函数可递归，也可保存、传参或返回；闭包捕获定义处的环境。调用参数个数必须匹配。

函数内被赋值、增减、用作循环变量或定义为嵌套函数的名字，在整个函数内均为局部名字，包括未执行的分支；参数也是局部名字。读取尚未赋值的局部名字报错。可读取外层值、修改外层列表内容，不能直接重新绑定外层名字。

```pymoji
🏭阶乘🤜n🤛👉🤔n≤1👉↩️1👈↩️n✖️阶乘🤜n➖1🤛👈📢阶
乘🤜6🤛                                         
```

输出 `720`。

## 输入输出与内置函数

`👂` 读一行，移除末尾 CR/LF。去除首尾空白后若为不超过 3000 字符的 ASCII 带可选正负号整数或小数，且结果有限，则返回数字；否则保留原行作为文字。空行得到空文字，EOF 得到 `🕳️`。运行时输入不受源码字符禁令或空白删除规则限制。

`📢`、`💬` 按顺序求值，每项求值后立即固定显示内容。文字直接显示；列表内文字显示 emoji 引号和空白转义；列表循环引用显示 `🎁…🎀`。输出不截断，显示格式不保证可重新当源码读取。

| 调用 | 结果 |
| --- | --- |
| `👑🤜值1,值2🤛`、`👑🤜列表🤛` | 最大值，至少一个值 |
| `🐜🤜值1,值2🤛`、`🐜🤜列表🤛` | 最小值，至少一个值 |
| `🎲🤜n🤛`、`🎲🤜a,b🤛` | 1 到 n、a 到 b 的随机整数，含两端 |
| `🔃🤜列表🤛` | 升序新列表，原列表不变 |

随机边界须为整数或整数值小数，下界不大于上界；最大、最小和排序遵循大小比较规则。内置函数名可以被赋值覆盖。

## 等价符号

| 主写法 | 别名 |
| --- | --- |
| `⬅️`、`⬆️`、`⬇️` | `←`、`↑`、`↓` |
| `➕`、`➖` | `+ ＋`、`- − －` |
| `✖️`、`➗` | `* × ＊`、`/ ÷ ／` |
| `✂️`、`🥡`、`🚀` | `//`、`% ％`、`^ ＾` |
| `=`、`≠` | `== ＝ ⚖️`、`!=` |
| `<`、`>`、`≤`、`≥` | `＜`、`＞`、`≦ <=`、`≧ >=` |
| `∈`、`,` | `: ：`、`， 、` |

## 运行选项与边界

```sh
python pymoji.py 程序.pymoji
python pymoji.py -c '📢1➕2'
python pymoji.py 程序.pymoji --format --width 48 -o 成品.pymoji
python pymoji.py 成品.pymoji --check-rectangle
```

Shell 引号不属于 pymoji 源码。`--tokens` 只列词法记号，`--seed N` 固定随机种子。`--tokens`、`--format`、`--check-rectangle` 互斥，后两者检查语法但不执行程序。

不设源码行数、语句数、执行步数、输入输出行数、输入单行长度和文字长度上限。保留运行时额外内存保护（`--max-mem MB`，默认 256，0 关闭）、函数调用深度保护（`--max-depth N`，默认 1000，范围 1–100000）、数字字面量 3000 字符和整数结果 10000 二进制位保护；实际运行也受宿主内存和调用栈约束。

执行前整体检查字符和语法。错误写标准错误并定位物理行；运行出错前已有输出保留。退出码：0 正常，1 语言或排版错误，2 参数或文件错误，130 运行中被 Ctrl+C 中断。
